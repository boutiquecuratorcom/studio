## AI DEVELOPMENT RULES

This repository uses a protected AI development workflow.

Before making any code changes, AI tools MUST read:

PROTOTYPER_RULES.md

Important rules:
• Do NOT modify locked files listed in PROTOTYPER_RULES.md
• Do NOT refactor unrelated code
• Make the smallest possible change required

If a change appears to require editing a locked file, STOP and ask first.
